# dsh-prompt-predict-adaptive

Codex 风格的输入框预测：每轮对话结束后，由**当前会话所选模型**起草你的下一句话，以灰色幽灵文本显示在输入框上方，按 **Tab** 填入。

DeepSeek Harness 插件。装上即用，官方插件页可开关，卸载不留残余。

> ## ⚠️ 先读这一段：每一轮都会多一次模型调用
>
> **这个插件会在每轮对话结束后，额外发起一次完整的模型请求。** 它用的是你当前会话选中的那个模型和 provider，计入你自己的额度。
>
> - 一次预测 = 一次完整调用，**不是**免费的后台操作
> - 上下文越长，这次调用越贵：它会重放对话（`完整上下文` 模式为整段，`最近轮次` 模式为末尾几轮）
> - 按 Tab 接受或按 Esc 丢弃**都不退款**——钱在预测生成时就已经花了
> - 嫌贵可以随时在插件页关掉总开关；也可以关掉「并入工作区状态」减少 prompt 体积
>
> 如果你的额度按 token 计费且比较紧张，**建议先关掉它**，或者只在长会话里打开。这是这个插件唯一的实质性成本。

## 它做什么

```
你：帮我把这个函数改成异步的
助手：（改完了）

        ↓ 约 4 秒后，输入框上方出现灰字

继续把调用方也改掉，然后跑一次测试                    [Tab]
```

按 **Tab** 填入草稿，然后你可以编辑或直接发送。按 **Esc** 丢弃这一条。

清空输入框后，刚才那条建议会**自动回来**，不需要手动恢复。

## 为什么不是"又一个自动补全"

三个设计决定让它不同于简单的文本补全：

**1. 用你自己的模型，不用官方额度**

预测目标从 `session.requestHeader().config` 读取——那是上一次真实请求被路由时写进会话日志的持久封套。

```js
const routed = agent.session.requestHeader()?.config;
if (routed === undefined || !routed.provider || !routed.model) {
  return { text: "" };  // 宁可不预测，也不换路由计费
}
```

**没有 fallback 到默认 provider。** 会话还没路由过请求时，插件产出空结果，而不是悄悄换一条路由。

**2. 不污染主上下文**

预测直接走 `ctx.llm.stream()`，**不是 agent step**：不写 session log、不产生 surface 节点、不进 transcript、不参与 replay。

**3. 会学习你的措辞**

打开「自适应」后，它记录你按 Tab 接受的、和按 Esc 丢弃的草稿，把示例附在下次指令末尾。几次之后，建议的语气和长度会向你靠拢。

## 安装

```bash
dsh plugin add dsh-prompt-predict-adaptive
```

或在 Harness 的**设置 → 插件 → 添加插件**中填入包名。

安装后刷新页面。

## 配置

在**设置 → 插件 → 输入框预测**中调整：

| 选项 | 默认 | 说明 |
|---|---|---|
| 输入框预测 | 开 | 总开关 |
| 自适应 | 开 | 从采纳/丢弃的草稿学习措辞。关闭后行为与基础版一致 |
| 并入工作区状态 | 开 | 把本会话改过的文件清单加入上下文，让建议能点名具体文件 |
| 继承会话权限 | 开 | 告知预测当前沙箱与审批状态，避免建议无权执行的动作 |
| 预测上下文 | 完整 | `完整上下文` 重放整段对话；`最近轮次` 只保留末尾几轮 |
| 保留轮数 | 6 | `最近轮次` 模式下保留几轮 |
| 诊断端点 | 关 | 开发用。开启后 `/diagnose` 可手动触发一次预测（会消耗一次模型调用并转发转录） |

改动后点**保存**，会显示「已保存设置」。

## 工作方式

### 触发

三个信号互为备份，汇入一个 400ms 去抖，一个 turn 只预测一次：

| 信号 | 作用 |
|---|---|
| `session/event` → `turn/end` | 持久化事件，主依据 |
| `agent/status` → `idle` | 覆盖 abort/error 等非正常结束 |
| `agent/turn-stopping` | 循环自身的边界 |
| 2 秒轮询 | **兜底**：直接读会话日志的 `turn/end` 计数，不依赖事件分发 |

轮询是关键。DSH 的 agent 事件走作用域化分发（scoped dispatch），插件监听器实测可能收不到；而 `session.eventAt(seq)` 是同步读取，只要 turn 真的结束就一定读得到。空闲时只做数值比较，不产生模型调用。

### 上下文

重放对话为**纯文本转录**，作为单条 user 消息发送：

```
You are a transcript analyst...
=== TRANSCRIPT ===
USER: ...
ASSISTANT: ...
```

**刻意不传 `tools`、`toolHistory`、`system`。** 早期的实现在传了这些之后，模型会试图调用工具（返回 `finish: tool-calls` 或 `<｜｜DSML｜｜ calls>` 标记），产出 2KB 废文本而非一行建议。纯文本转录让它没有角色可延续、没有工具可调用。

### 失败可见

限流或额度耗尽时，输入框位置显示橙色提示，而不是静默消失：

```
prediction skipped: the provider is rate limited or out of quota
```

## 隐私与安全

- 预测内容**不写入**会话日志，不参与回放
- HTTP 桥接有同源校验：只接受来自页面自身 origin 的请求，伪造 `Origin` 一律 403
- 诊断端点默认关闭；关闭时返回 403
- 唯一的持久化数据是 `$DSH_PROFILE_DIR/prompt-predict-adaptive/` 下的两个 JSON：
  - `config.json`：你的设置
  - `feedback.json`：学习到的措辞示例（最多 20 个会话 × 8 条）
- 卸载时这两个文件连同目录一起删除

学习数据**可以直接删**，删掉只丢失措辞偏好，不影响任何功能。

## 已知限制

- **延迟不是零。** 生成一次建议通常要 4–10 秒，长会话更久；这段时间输入框是空的，不要以为是坏了。
- **只读对话，不读项目文件。** 工作区状态是借用宿主已有的变更摘要（改过哪些文件、增删多少行），不主动扫描文件系统。
- **失败不重试。** 限流或额度耗尽时跳过这一轮，并在插件设置页显示原因；等下一轮自动恢复。
- **Web UI 插件需要刷新页面**才会加载或消失。
- **每轮多一次调用**——见开头的成本提示，这里不再重复。

## 卸载

插件页点卸载即可。会移除：

- `package.json` 中的依赖
- profile 的 bundle 选择项
- `node_modules` 链接
- 插件自己的状态目录

pnpm 的 `link:` 安装偶尔会在 `node_modules` 留下一个悬空软链接，可手动清理：

```powershell
Remove-Item "$env:DSH_PROFILE_DIR\node_modules\dsh-prompt-predict-adaptive" -Recurse -Force
```
